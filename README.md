## 🚀 Getting Started

To run the examples, make sure you have Python installed on your computer.

Check your Python version:

```bash
python --version
```

or:

```bash
python3 --version
```

Clone this repository:

```bash
git clone https://github.com/your-username/python-codes.git
```

Navigate to the project directory:

```bash
cd python-codes
```

Run a Python file:

```bash
python filename.py
```
